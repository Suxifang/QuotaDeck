余度 0.2.5

- Sub2API 站点开启人机验证时，自动改用应用内站点登录页；完成验证码、邮箱密码及站点要求的两步验证后，自动核验登录用户、关联当前 API Key 并读取使用记录。密码不进入应用的登录交接数据。
- 登录失败时区分人机验证、凭据错误及其他站点拒绝，不再将所有 400／401／403 错误统一提示为检查邮箱密码；原来的邮箱密码登录仍可使用，并提供“验证登录”入口。
- 常用账号小组件改为等宽列，统一金额区域、进度区域和查询时间的位置；余额账号与有总额度的账号混排时仍保持对齐。
- 每个账号直接显示具体查询时间，删除底部重复的静态提示；待更新、查询失败和时间未知分别提示，不把手机查询时间当作后台采样时间。
- 进度条旁增加剩余百分比，保留真实的 0%；只有余额、没有总额度的账号显示提供方或其他有效信息，不虚构进度。
- 整理小号卡片的文字层级和间距；锁屏卡片补充额度类型，保留点击进入账号详情。
- 应用内预览同步更新，布局检查增加两账号混排、长名称与金额、旧缓存、过期和系统着色场景。
- 包含 0.2.4 的小组件存储修复：省略未知百分比，避免将空值写入 iOS 系统存储；同步失败时显示具体步骤。

关于小组件

正式包使用 `group.app.quotadeck.mobile`。本机专用兼容包按已授权的共享组另行生成，不替换正式发行附件。桌面显示的是最近一次查询结果；应用关闭后不会主动向站点查询，超过 15 分钟或已过重置时间会标记待更新。

系统要求：iOS 16.4 或以上。
