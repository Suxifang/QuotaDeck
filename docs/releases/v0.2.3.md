余度 0.2.3

- 底栏支持按住拖动：玻璃胶囊跟随手指移动、轻微放大，松手吸附到“总览、连接、设置”；拖出底栏取消，避免拖动途中反复跳页。支持点按及系统减弱动态效果。
- 首页额度卡片右上角增加“置顶 / 已置顶”入口，不必再进入管理页寻找。
- Sub2API 套餐增加“登录站点查看记录”，支持站点邮箱密码及两步验证码。登录后自动关联当前 API Key，显示模型、费用、时间和 Token 等调用详情，并支持分页。额度 API Key 与记录登录状态分开保存在钥匙串。
- 套餐记录逐行核对用户与密钥，站点未提供兼容接口、隐藏完整密钥、要求网页人机验证或第三方登录时会提示；不会扩大为账号全部记录。
- 改进小组件打包：用不含开发者证书的 ad-hoc 签名嵌入主应用和扩展的共享组权限，便于重签工具读取并保留；发布前校验两边的共享组配置和包内权限。安装前仍需自行重新签名。
- 简化小组件设置：账号选择与同步集中显示，外观预览默认收起；明确说明“无需置顶”及共享空间不可用的原因。

关于小组件

本版改进了包内共享权限的保留方式，但所用自签证书与描述文件仍须允许 `group.app.quotadeck.mobile`，且主应用与小组件均须保留该组。若安装后仍提示共享空间不可用，需要检查实际重签结果；置顶和重复同步无法补齐签名权限。真机显示仍需安装后验证。

系统要求：iOS 16.4 或以上。iOS 26 支持原生玻璃材质；较旧系统使用磨砂效果。
