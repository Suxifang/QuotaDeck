# 余度 · Yudu 安装与更新

在 iPhone 上集中查看 Sub2API 套餐、反代账号及其他 API 额度。

源码和安装包统一在公开的 `Suxifang/Yudu` 仓库维护，使用 MIT 许可证。请从该仓库的 [最新正式版](https://github.com/Suxifang/Yudu/releases/latest) 下载 IPA；源码目录不存放安装包。

## 安装与更新

下载最新正式版的 `Yudu-版本号.ipa`，导入 LCSign，使用自己的证书签名安装。应用内可在「设置 → 软件更新」或主页右上角更新入口检查、下载并校验新版本，再通过系统分享导入 LCSign。

覆盖更新时，请使用与已安装版本相同的签名身份和应用标识。请同时签署主应用及小组件扩展，并保留 App Group 权限。安装成功后打开应用确认版本。首次接入此更新渠道需手动安装此版本。

0.2.3 起，IPA 使用不含开发者证书的 ad-hoc 签名嵌入两边的共享组权限，方便 LCSign 读取并在重签时保留；它仍需用自己的证书重新签名才能安装。共享组为 `group.app.quotadeck.mobile`，证书与描述文件也必须允许该权限。构建和包内检查只能验证打包结果，不能代替实际重签后的权限验证。

小组件不要求先置顶。在「设置 → 桌面与锁屏小组件」选择关注账号、同步，再到 iPhone 主屏幕添加余度。如果提示“共享空间不可用”，表示当前安装无法访问共享组；置顶或反复同步无法补齐签名权限。确认主应用与小组件均保留后重新签名覆盖安装。同步成功但旧卡片仍无数据时，可移除旧卡片再添加。

已安装 0.2.0 或 0.2.1 的用户，请手动从上述主仓库下载 0.2.2 或更新版本并覆盖安装一次。旧版的更新地址已停用；安装新版后，后续更新统一使用 `Suxifang/Yudu`。

最低系统 iOS 16.4；iOS 26 支持原生 Liquid Glass。应用内的查询凭据保存在设备钥匙串，不随更新包上传。

自动检查默认关闭；开启后在启动或回到前台时最多每 6 小时检查一次。下载和安装由用户发起，不会在后台静默替换已安装的应用。

开源组件与完整许可见应用「设置 → 开源致谢」及主仓库的 `THIRD_PARTY_NOTICES.md`、`licenses/`。
