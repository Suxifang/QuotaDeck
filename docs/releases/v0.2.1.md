此版本早期使用的更新地址已停用。请从 Suxifang/Yudu 的 Releases 手动下载并覆盖安装 0.2.2 或更新版本一次。沿用原签名身份、Bundle ID 和 App Group，同时签署主应用与小组件扩展。
