余度 0.2.0

- 正式启用「余度」名称与留白刻度图标。
- 天青与鼠尾草色的通透磨砂界面，搭配顺滑的液态玻璃底栏。
- 新增「设置 → 版本更新」：检查 GitHub 正式版本、查看更新内容、下载并校验 IPA，再导入 LCSign。
- 自动检查可选，默认关闭；更新包支持取消下载与缓存复用。
- 提供桌面及锁屏小组件，支持 Sub2API 套餐、反代额度及其他 API 接口。

安装说明

这是未签名 IPA，请用自己的证书在 LCSign 中签名安装。覆盖升级时沿用原签名身份与应用标识，同时签署小组件并保留 App Group。首次安装本版本后，即可使用新的应用内更新入口。

系统要求：iOS 16.4 或以上。iOS 26 显示原生玻璃效果。
