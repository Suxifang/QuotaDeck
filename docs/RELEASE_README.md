# 余度 · Yudu 安装与更新

在 iPhone 上集中查看 Sub2API 套餐、反代账号及其他 API 额度。

源码和安装包统一在公开的 `Suxifang/QuotaDeck` 仓库维护，使用 MIT 许可证。请从该仓库的 [最新正式版](https://github.com/Suxifang/QuotaDeck/releases/latest) 下载 IPA；源码目录不存放安装包。

## 安装与更新

下载最新正式版的 `Yudu-版本号.ipa`，导入 LCSign，使用自己的证书签名安装。应用内可在「设置 → 版本更新」检查、下载并校验新版本，再通过系统分享导入 LCSign。

覆盖更新时，请使用与已安装版本相同的签名身份和应用标识。请同时签署主应用及小组件扩展，并保留 App Group 权限。安装成功后打开应用确认版本。首次接入此更新渠道需手动安装此版本。

已安装 0.2.0 的用户可从原更新入口取得 0.2.1 过渡包。安装 0.2.1 后，应用会统一从 `QuotaDeck` 仓库获取后续版本；原发行仓库不再发布新版本。

最低系统 iOS 16.4；iOS 26 支持原生 Liquid Glass。应用内的查询凭据保存在设备钥匙串，不随更新包上传。

自动检查默认关闭；开启后在启动或回到前台时最多每 6 小时检查一次。下载和安装由用户发起，不会在后台静默替换已安装的应用。

开源组件与完整许可见应用「设置 → 开源致谢」及主仓库的 `THIRD_PARTY_NOTICES.md`、`licenses/`。
